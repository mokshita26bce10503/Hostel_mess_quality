# Hostel Mess Quality Assessment and Analytics System

## Overview
This project helps collect and analyze student feedback regarding hostel mess food.

## Features
- Food Feedback Collection
- Complaint Management
- Waste Monitoring
- Food Voting System
- Analytics Report Generation
